# API Reference (summary)

Interactive docs: `http://localhost:8000/docs` (OpenAPI, auto-generated by FastAPI).

## Auth
- `POST /api/auth/register` — {name, email, password, business_name} → JWT + tenant (201)
- `POST /api/auth/login` — {email, password} → JWT
- `GET  /api/auth/me` — current user (Bearer)

## Business (tenant-scoped; `X-Business-Id` for platform admins)
- `GET/PATCH /api/business`
- `GET/POST /api/business/whatsapp/connect`, `GET /api/business/whatsapp`
- `GET/PATCH /api/business/ai-settings`

## Menu
- `GET/POST /api/menu`, `PATCH/DELETE /api/menu/{id}`
- `GET/POST /api/menu/categories`

## Orders / Bookings / Customers
- `GET/POST /api/orders`, `GET/PATCH /api/orders/{id}` (status flow)
- `GET/POST /api/bookings`, `PATCH /api/bookings/{id}/cancel`
- `GET /api/customers`

## Conversations
- `GET /api/conversations?q=&status_filter=`
- `GET /api/conversations/{id}` (full message history)
- `POST /api/conversations/{id}/reply|takeover|close`

## Knowledge (RAG)
- `GET /api/knowledge`
- `POST /api/knowledge/documents` (form: title, content)
- `POST /api/knowledge/upload` (.txt/.md/.csv/.json ≤2 MB)
- `DELETE /api/knowledge/{id}`, `POST /api/knowledge/reindex`, `POST /api/knowledge/search` (form: query)

## Analytics / Billing
- `GET /api/analytics?days=30`, `GET /api/analytics/usage`
- `GET /api/subscription`, `GET /api/subscription/plans`, `POST /api/subscription/checkout?plan=business` (mock)

## WhatsApp
- `GET /api/webhooks/whatsapp?hub.mode=subscribe&hub.verify_token=…&hub.challenge=…`
- `POST /api/webhooks/whatsapp` (Cloud API payload; `X-Hub-Signature-256` enforced when WHATSAPP_APP_SECRET set)

## Admin (platform_admin only)
- `GET /api/admin/businesses`, `PATCH /api/admin/businesses/{id}/status?action=suspend|activate`, `GET /api/admin/overview`
